# IDR navigation demo

This is a dependency-free browser replay surface for presentations and
deterministic UI checks. Open `index.html` directly in a browser. It uses
original SVG/CSS artwork and simulates the same high-level states as the
Android shell: GNSS-aided navigation, a GNSS blackout, inertial dead
reckoning, recovery, and return to GNSS-aided mode.

It is not a live map, a sensor implementation, or evidence of field accuracy.
The Android application remains the executable surface for phone IMU/GNSS
capture.
